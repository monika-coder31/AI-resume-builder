# AI Resume Builder

An AI-powered web application that helps users create professional, ATS-friendly resumes by simply entering their details and choosing a template. Includes an AI-based ATS Score Checker that compares your resume against a job description and highlights missing keywords.

## 🚧 Project Status
In Development — Phase 1: Planning & Setup

## 💡 Problem Statement
Many students and job seekers struggle to create well-formatted, professional resumes and often don't know whether their resume will pass through Applicant Tracking Systems (ATS) used by companies. This project solves both problems in one tool.

## ✨ Features
- [ ] Simple form to enter personal details, education, skills, experience, and projects
- [ ] Multiple professional resume templates to choose from
- [ ] Real-time resume preview
- [ ] Download resume as PDF
- [ ] AI-powered ATS Score Checker — matches resume content against a job description
- [ ] Missing keyword suggestions to improve resume-job match
- [ ] (Planned) AI-based resume bullet point suggestions

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React, Tailwind CSS |
| Backend | FastAPI (Python) |
| ATS/NLP Logic | scikit-learn (TF-IDF + Cosine Similarity) |
| PDF Generation | html2pdf.js |
| Deployment | Vercel (Frontend), Render (Backend) |
